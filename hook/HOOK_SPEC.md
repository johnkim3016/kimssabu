# 주식차트 김싸부 엔딩 후킹 이미지 제작 규격 (2026-11-12)

다른 AI가 같은 이미지를 다시 만들거나 문구만 바꿔 만들 때 이 규격을 그대로 따르세요.

## 0. 가장 쉬운 방법 (권장)

1. 원본 틀을 그대로 씁니다.
   - 쇼츠용: https://johnkim3016.github.io/kimssabu/hook/end_shorts.html
   - 롱폼용: https://johnkim3016.github.io/kimssabu/hook/end_longform.html
2. 브라우저 창 크기를 쇼츠 1080×1920, 롱폼 1920×1080 으로 맞추고 화면 전체를 캡처(PNG)합니다.
3. 문구를 바꿀 때는 HTML 안의 글자만 바꿉니다. 크기·색·배치는 건드리지 않습니다.
4. 완성본 예시: hook/end_shorts.png, hook/end_longform.png

이미지 생성 AI(그림 AI)는 한글 글자를 자주 틀리게 그리므로, 글자가 들어가는 이 이미지는 HTML 틀로 만드는 것을 원칙으로 합니다.

## 2. 디자인 규격

- 바탕 #0a0a0b(거의 검정), 사진·카드 뒤에 금색 빛 번짐(rgba(212,175,55,.3) 원형 그라데이션)
- 금색: 강조 글자 #f1cd63, 테두리 #d4af37, 번호 원 #f3d470→#c99b2e 그라데이션
- 본문 글자 #f6f1e4, 보조 글자 #8a8372, 유튜브 링크 파랑 #3ea6ff
- 글꼴: Noto Sans KR (제목 900, 본문 700)
- 사진: 채널 프로필 사진(원형)

## 3. 쇼츠용 9:16 (1080×1920) 배치 (위에서 아래로)

1. 배지(금색 테두리 알약): "주식차트 김싸부 · 무료 신청"
2. 제목 3줄(92px): "삼전닉스 동호회방 +" / (금색) "급등주 무료 알림" / "신청하는 법"
3. 혜택 칩 2×2: 📊 삼전닉스 동호회방 · 🚀 급등주 무료 알림 · 💬 무료 정보방 · 👤 김사부 직접 연락
4. 채널 머리 화면 카드: 원형 사진 + "주식차트 김싸부" + "@김싸부-1963" + 설명 첫 줄 + 파란 링크 "🔗 url.kr/388n97"(금색 테두리·빛) + 금색 꼬리표 "여기 누르기 ☝"
5. 단계: ① 아래 @김싸부-1963 누르기 ② 채널 맨 위 파란 링크 → 금색 상자 "url.kr/388n97", 그 아래 "질문 6개 · 1분이면 충분해요"
6. 왼쪽 아래를 가리키는 금색 곡선 화살표(쇼츠에서 채널 이름이 뜨는 자리)
7. 오른쪽 아래 작은 고지 2줄
- 쇼츠 화면 아래 약 15%는 유튜브가 제목·채널 이름으로 덮으므로 화살표와 고지 말고는 넣지 않습니다.

## 4. 롱폼용 16:9 (1920×1080) 배치

- 왼쪽: 배지 → 제목 3줄(70px, "신청하기") → 혜택 칩 2×2 → ① 설명란 첫 줄 링크 누르기 ② 또는 채널 맨 위 파란 링크 → 금색 상자 "url.kr/388n97" → 맨 아래 "질문 6개 · 1분이면 충분해요" + 고지
- 오른쪽: 채널 머리 화면 카드(쇼츠와 같은 구성)

## 5. 쓰는 법

- 쇼츠: 마지막 2~3초에 깔고, 마지막 대사와 함께 씁니다.
  - 아빠·아들: 아들 "아빠, 삼전닉스 동호회방은 어떻게 들어가?" → 아빠 "채널 이름 누르고 맨 위 링크. 무료야."
  - 했제: 아빠 "아들아, 급등주 알림은 채널 맨 위 링크에서 무료로 받는다."
- 롱폼: 엔딩 화면 또는 마지막 안내 구간에 씁니다.

## 6. 넣으면 안 되는 것

- 종목 수익률 나열, "또 터진다"·"무조건" 같은 단정·보장 표현
- 1:1 종목 상담을 약속하는 문구
- 설명 첫 줄·짧은 주소와 다른 문구(시청자가 채널에 들어갔을 때 같은 말이 보여야 신청까지 감)
